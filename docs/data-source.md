# 데이터 원천 결정

결정: **Open-Meteo의 서울 고정 지점 모델 기반 지상 2m 현재 기온** 한 개를 사용합니다. 고정 좌표는 37.5665, 126.9780이며 사용자의 위치·브라우저 위치 권한·개인 기록을 사용하지 않습니다.

원천 설정은 [live-source.json](../config/live-source.json)에 있습니다.

## 선정 이유와 값의 의미

계정·비밀키 없이 조회할 수 있고 숫자·단위·원천 기준 시각이 응답에 함께 있습니다. 무료 API는 비상업적 교육용 범위로 사용합니다. 공식 문서는 현재 값을 15분 간격 기상 모델 데이터 기반으로 설명하므로, 관측소의 실측 기온이라고 표시하지 않습니다.

화면 표기는 '서울 현재 기온'과 'Open-Meteo · 모델 기반 · 지상 2m · 고정 대표 지점'으로 계획합니다. 요청 좌표와 응답 격자 좌표가 다를 수 있음을 상세 정보에서 설명합니다. 이 수치는 서울 전체나 사용자 주변의 정확한 기온을 뜻하지 않습니다.

## 응답과 공통 모델의 매핑

| 공통 필드 | 원천/규칙 |
| --- | --- |
| signal_id | `seoul-temperature-2m` 고정 |
| normalized_value | `current.temperature_2m`, 유한한 숫자만 허용 |
| unit | `current_units.temperature_2m`, `°C`인지 검증 |
| source_name | `Open-Meteo` |
| source_url | 고정 API URL 전체; 비밀값 없음 |
| source_time | `current.time` Unix 초를 UTC ISO 8601로 변환 |
| fetched_at | 실제 조회가 성공한 서버 시각; 원천 시각을 복사하지 않음 |
| record_timezone | `Asia/Seoul` |
| record_date | `fetched_at`을 KST로 변환한 날짜 |

`timeformat=unixtime` 응답의 시간은 Unix UTC 초입니다. 원천의 `utc_offset_seconds`를 다시 더하지 않습니다. 표시할 때만 KST로 변환합니다. `current_units.time`이 `unixtime`인지도 검사합니다. 값·단위·필수 시각·응답 시간대 등이 바뀌면 `schema_error`로 분리하고 기존 정상값을 유지합니다.

비교는 같은 원천·단위의 나중 일별값에서 이전 일별값을 뺍니다. 증가/감소/같음과 절대 크기(°C), 두 날짜·시각을 표시합니다. 조회 시각이 서로 다를 수 있으므로 일평균 기온 차이로 설명하지 않습니다. 전날 기록이 없으면 실제 비교 날짜를 명시합니다.

## 이용 조건과 호출 계획

2026-10-26 확인한 공식 약관상 무료 API는 비상업용이며, 분당 600·시간당 5,000·일당 10,000회 미만 호출 제한이 있습니다. 데이터에는 CC BY 4.0 출처 표시가 필요합니다. 광고·구독을 추가하거나 상업적으로 사용할 때는 제공 조건을 다시 검토합니다.

화면과 README에 `Weather data by Open-Meteo.com (CC BY 4.0).` 및 원천 링크를 표시합니다. 조회 진행 중 중복 클릭을 막고 서버에서 짧은 간격의 중복 원천 호출을 제한하는 방향으로 구현합니다. 공유 배포 환경에서는 더 이른 호출 제한이 생길 수 있으므로 429를 별도로 처리합니다. 자동 주기 갱신은 후속 U9로 남깁니다.
