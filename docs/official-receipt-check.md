# 공식 과정 기록·영수증 확인 결과

2026-10-27 KST, 사용자 로그인 후 [ALEPH 과제 화면](https://aleph-omega.vercel.app/cortex?panel=tasks)의 T04 카드 5와 제출 준비의 **선택 과정 기록 남기기**를 직접 확인했습니다. 현재 화면은 **현재 과정 기록 0개 보기**로 표시합니다. 공식 영수증 payload·봉인·발급 날짜를 대조할 원문이 없어 영수증 대조 결과는 **미실시**입니다. 앱 보관본을 공식 영수증으로 대신하거나 일치로 판정하지 않았습니다.

## 현재 웹 안내와 확보한 공개 계약의 차이

| 구분 | 2026-10-27 로그인한 웹 화면 | 2026-10-26 확보한 공개 계약 v2 |
| --- | --- | --- |
| C22 | 서로 다른 Asia/Seoul 실제 날짜에 조회한 공개 원천 기록 정확히 2건 보존 | 봉인된 t04_day 영수증 정확히 2건, server_created_at의 KST 날짜가 다름 |
| C23 | 두 기록의 URL·원천 관측 시각·값·단위가 일별 저장값·화면값과 일치 | 봉인 영수증 payload와 앱 저장값·화면값 일치 |
| C24 | 조회 날짜순으로 변화량 재계산 | 영수증 server_created_at 순서로 변화량 재계산 |
| 과정 기록 | 선택 사항이며 없어도 제출·강사 승인·마스터 승인을 막지 않음 | 제출·승인과 후행 채점을 분리하되 영수증 기반 채점 조건을 명시 |

현재 웹의 과정 기록 입력 도움말에는 여전히 실제 이틀 판정에 **플랫폼의 Asia/Seoul 서버 날짜**를 사용한다고 적혀 있습니다. 웹의 카드 문구·입력 도움말·보관된 공개 계약이 완전히 일치하지 않습니다. 따라서 영수증이 없으면 제출·승인이 불가능하다고 안내하지 않으며, 공개 계약의 영수증 기반 후행 채점까지 통과했다고 단정하지도 않습니다. 최종 채점에 적용되는 기준의 일치 여부는 확인이 필요합니다.

## 확인된 공식 입력 경로

T04 → 제출 준비 → **선택 과정 기록 남기기** → **실제 공개 원천 기록**에서 공개 HTTPS 원천 URL, 시간대가 있는 RFC 3339 원천 관측 시각, 정규화 숫자, 단위를 입력하는 화면입니다. **실제 공개 원천 기록 기록 남기기** 버튼과 기록 개수 보기가 있습니다. 플랫폼은 작성 시각·순서를 자동 보관하고 원천 URL을 대신 호출하지 않는다고 안내합니다.

이번 요청은 기존 공식 영수증 대조이므로 새 과정 기록이나 제출물을 생성하지 않았습니다. 지금 기록을 작성해도 플랫폼 작성 시각을 과거 앱 조회 시각으로 대신할 수는 없습니다. 영수증 원문이 확보되면 `source_url`, `source_observed_at`, `normalized_value`, `unit`을 고정 보관본과 대조하고, 원문의 `server_created_at` 날짜·순서를 별도로 확인합니다.

## 기존 앱 값 대조 상태

10월 26일 **14.6°C**와 27일 **12.8°C**의 원자료·저장값·고정 화면·**1.8°C 감소**는 이미 일치 확인했습니다. 현재 웹 카드 C22~C24가 설명하는 앱 기록 대조는 이 자료로 확인할 수 있습니다. 이 확인을 공식 봉인 검증이나 최종 채점 결과로 확대하지 않습니다.
