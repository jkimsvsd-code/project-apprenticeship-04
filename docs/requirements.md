# 요구사항과 승인 범위

기준 자료: 사용자가 제공한 과제 4 PDF 5쪽. 웹의 최신 과제 버전과 공식 합성 자산 계약은 아직 대조하지 않았습니다.

## 필수 요구사항

| 번호 | 요구사항 | PDF 통과 기준 |
| --- | --- | --- |
| R1 | 비개인 공개 원천의 실제 동적 값 하나 조회 | T04-C03 |
| R2 | 값·단위·출처·관측 시각·조회 시각·기준 시간대 표시, 원자료·저장값·화면값 대조 | T04-C04~C10 |
| R3 | 느림·원천 401/403·호출 제한·오프라인·형식 변경을 합성 재생 | T04-C12~C16, C26 |
| R4 | 마지막 정상값 보존, 오래된 값 표시, 재시도 및 지정 fixture 복구 | T04-C17~C19 |
| R5 | 같은 KST 날짜 성공은 한 건으로 합치고 다음 날짜는 새 기록 | T04-C20~C21 |
| R6 | 다른 실제 KST 날짜 기록 정확히 2건, 각 값의 출처 대조와 변화량 재계산 | T04-C22~C24 |
| R7 | 결과물·소스 무로그인 공개, 비밀키·실제 개인정보·개인 기록 노출 0건 | T04-C01, C11, C25 |
| R8 | 공식 자산 ID·해시 및 시험 증거, 확인법 4줄, AI·본인 판단 3줄 | 카드 3 증거 기준, T04-C27~C28 |

PDF에 T04-C02는 제시되어 있지 않습니다. 내용을 추정하여 추가하지 않습니다.

## 승인된 UX 기능

| ID | 기능 | 완료 판단 |
| --- | --- | --- |
| U1 | 첫 방문·기록 부족 안내 | 조회 전·첫 성공 후·이틀 기록 확보 상태에서 다음 행동을 알 수 있음 |
| U2 | 마지막 성공 경과 시간 | 절대 시각과 경과 시간을 함께 표시하고 상태를 색상·문구·아이콘으로 전달 |
| U3 | 요청 진행·중복 클릭 방지 | 진행 중임을 표시하고 같은 화면에서 중복 요청을 막음 |
| U4 | 재시도 대기 안내 | 원천이 제공한 대기 시간을 반영하고, 미제공 시 이를 구분해 안내 |
| U5 | 변화량 계산 상세 | 비교 날짜·두 저장값·단위·계산식을 펼쳐 볼 수 있음 |
| U6 | 모바일·키보드 접근성 | 좁은 화면에서 주요 정보가 읽히고 키보드 조작·초점·상태 안내가 동작 |
| U7 | 공개 심사용 합성 재생 패널 | 정상·실패 5종·복구를 재생하고 상태·기록 건수 변화를 확인 |

## 현재 범위 밖

- U8 검증 결과 복사·다운로드: 미승인. 구현 대상에서 제외합니다.
- U9 자동 갱신·장기 추이 차트: 후속 확장으로 승인되었습니다. 현재 버전에는 포함하지 않습니다.
- 다중 데이터 원천·사용자 계정·개인화·알림: 별도 요청 전에는 추가하지 않습니다.

## 완료 조건

앱 구현 완료와 과제 검증 완료를 구분합니다. 합성 시험이 통과해도 서로 다른 실제 KST 날짜의 기록 2건이 없으면 과제 검증은 미완료입니다. 기다린 시간은 과제의 계획 작업시간 6~7시간과 별개입니다.
